# Quick start

This path takes you from an empty workspace to a visible, reusable creative result.

## 1. Create or open a Canvas

A Canvas is the project boundary. It stores the visual graph, Library association, identities used by the project and its Automations.

In Scenelith Cloud, sign in at [scenelith.com](https://scenelith.com). On a self-hosted instance, open the URL configured by its operator.

## 2. Add source material

You can upload image or video files, import a public TikTok post, or start with an empty generator node. Imported and uploaded media is also available through the project Library.

## 3. Add visual references

References tell a generation what visual evidence matters. Add them from:

- the current Canvas;
- the project Library;
- a saved Character or Before/After Identity.

References remain attached to the node, so the reasoning behind a result stays visible.

## 4. Generate and choose an output

Open the generator, choose a compatible model, describe the change, and run it. Generated outputs remain grouped with their prompt and references. Select the output you want to continue with instead of losing earlier versions.

## 5. Reuse the work

When the result is repeatable, either:

- turn the sequence into an [Automation](/automation/overview);
- save visual evidence as an [Identity](/canvas/library-and-identities);
- or [connect an AI agent](/mcp/connect) and let it work through the same project boundaries.
