# Support

Support is a Cloud feature. Open it from the account/product menu. Every issue has one persistent thread; user and staff replies stay attached to that ticket.

## Create a ticket

Choose one area:

- Bug
- Generation
- Account
- Other

The subject must contain at least 4 non-space characters and is limited to 140. Details must contain at least 10 and are limited to 6,000. Include what happened, what you expected and steps to reproduce one issue.

## Ticket list

The list shows category, last update, subject, latest message, message count, status and priority indicator. Only your own tickets are visible to a normal account; support administrators can access the full queue.

## Conversation

Open a ticket to read the full thread and add a reply of up to 6,000 characters. While open, the thread refreshes every 30 seconds when the page is visible and also refreshes when the window regains focus.

Statuses are `open`, `in progress`, `resolved` and `closed`. Support staff can also set `normal`, `high` or `urgent` priority. A closed ticket is read-only.

Replies and status changes can create account notifications. The notification bell refreshes periodically; notifications can be opened individually or marked all read.
