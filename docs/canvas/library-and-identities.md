# Library and identities

## Library

Every project has a Library for uploaded, imported and generated media. Library assets remain durable even when they are not currently placed on the Canvas.

Use the Library to:

- place existing media on the Canvas;
- attach image or video evidence to a generation;
- build reusable Identities;
- inspect dimensions, duration, origin and generation metadata when available.

## Character Identity

A Character Identity contains one ordered `reference` group. Use it when the same person or character should stay recognizable across new scenes.

## Before / After Identity

A Before/After Identity contains two separately ordered groups:

- `before` for the starting state;
- `after` for the target or transformed state.

Keeping the groups separate prevents an agent or workflow from treating an After image as neutral character evidence.

## Adding references

An Identity reference must come from an approved Library image. Adding it copies the Library asset relationship into the selected Identity group; it does not delete or move the original asset.

## MCP access

An authorized agent can list identities and inspect bounded reference previews with read access. Creating an Identity or changing its groups additionally requires Identity write permission and Library access. See [MCP permissions](/mcp/permissions).
