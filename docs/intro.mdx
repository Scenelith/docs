## Understand the object model

Scenelith keeps four things deliberately separate:

| Object | What it owns |
| --- | --- |
| **Canvas** | The visible project graph: source media, nodes, connections and editable outputs. |
| **Library** | Durable uploaded, imported and generated image or video assets. |
| **Identity** | Reusable visual evidence for one Character or separate Before and After groups. |
| **Automation** | A typed workflow draft, immutable published versions, triggers and run history. |

That same model is used by the interface and by MCP. An agent does not get a second, simplified version of the product.

:::tip Choose your path
Use **Scenelith Cloud** when you want a managed account and infrastructure. Use **self-hosted Scenelith** when you want the runtime, media storage and provider credentials on infrastructure you control.
:::
